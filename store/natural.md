# Естественные науки

- **package:** `ru.cyberleninka.natural`
- **Название RuStore:** КиберЛенинка: Естественные науки
- **Категория RuStore:** Образование (или Книги и справочники)
- **Возрастной рейтинг:** 12+ (содержит рекламу)
- **Теги:** наука, математика, физика, химия, биология, научные статьи, библиотека, чтение

## Короткое описание (до 80 символов)
Статьи по математике, физике, химии, биологии — поиск и чтение офлайн.

## Полное описание
«КиберЛенинка: Естественные науки» — читалка научных статей раздела «Естественные и точные науки» научной библиотеки КиберЛенинка (рубрикатор ОЭСР).

Раздел включает:
• математику;
• компьютерные и информационные науки;
• физику;
• химические науки;
• науки о Земле и смежные экологические науки;
• биологические науки.

Возможности:
• поиск статей по всей библиотеке;
• рубрики раздела с постраничной загрузкой;
• полнотекстовое чтение с комфортной вёрсткой;
• закладки и история;
• офлайн-база для чтения без интернета;
• сохранение PDF и отправка ссылки.

Бесплатно, по модели открытого доступа. Источник — cyberleninka.ru. Приложение показывает рекламу (Appodeal).
