# Социальные науки

- **package:** `ru.cyberleninka.social`
- **Название RuStore:** КиберЛенинка: Социальные науки
- **Категория RuStore:** Образование (или Книги и справочники)
- **Возрастной рейтинг:** 12+ (содержит рекламу)
- **Теги:** социальные науки, психология, экономика, социология, право, политология, научные статьи, библиотека

## Короткое описание (до 80 символов)
Статьи по психологии, экономике, социологии, праву — чтение офлайн.

## Полное описание
«КиберЛенинка: Социальные науки» — читалка научных статей раздела «Социальные науки» научной библиотеки КиберЛенинка (рубрикатор ОЭСР).

Раздел включает:
• психологические науки;
• экономику и бизнес;
• науки об образовании;
• социологические науки;
• право;
• политологические науки;
• социально-экономическую географию;
• СМИ (медиа) и массовые коммуникации.

Возможности:
• поиск статей по всей библиотеке;
• рубрики раздела с постраничной загрузкой;
• чтение полного текста с комфортной вёрсткой;
• закладки и история;
• офлайн-база для чтения без интернета;
• сохранение PDF и отправка ссылки.

Бесплатно, по модели открытого доступа. Источник — cyberleninka.ru. Приложение показывает рекламу (Appodeal).
