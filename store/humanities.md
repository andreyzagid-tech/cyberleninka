# Гуманитарные науки

- **package:** `ru.cyberleninka.humanities`
- **Название RuStore:** КиберЛенинка: Гуманитарные науки
- **Категория RuStore:** Образование (или Книги и справочники)
- **Возрастной рейтинг:** 12+ (содержит рекламу)
- **Теги:** гуманитарные науки, история, философия, филология, искусство, научные статьи, библиотека, чтение

## Короткое описание (до 80 символов)
Статьи по истории, философии, филологии и искусству — читайте офлайн.

## Полное описание
«КиберЛенинка: Гуманитарные науки» — читалка научных статей раздела «Гуманитарные науки» научной библиотеки КиберЛенинка (рубрикатор ОЭСР).

Раздел включает:
• историю и археологию;
• языкознание и литературоведение;
• философию, этику, религиоведение;
• искусствоведение.

Возможности:
• поиск статей по всей библиотеке;
• рубрики раздела с постраничной загрузкой;
• чтение полного текста с комфортной вёрсткой;
• закладки и история;
• офлайн-база для чтения без интернета;
• сохранение PDF и отправка ссылки.

Бесплатно, по модели открытого доступа. Источник — cyberleninka.ru. Приложение показывает рекламу (Appodeal).
