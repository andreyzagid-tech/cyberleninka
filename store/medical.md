# Медицинские науки

- **package:** `ru.cyberleninka.medical`
- **Название (до 50):** КиберЛенинка: Медицина
- **Категория RuStore:** Образование (или Книги и справочники)
- **Возрастной рейтинг:** 12+ (содержит рекламу)
- **Теги:** медицина, наука, научные статьи, здравоохранение, чтение, библиотека, биотехнологии, здоровье

## Короткое описание (до 80 символов)
Научные статьи по медицине: поиск, чтение офлайн, PDF.

## Полное описание
«КиберЛенинка: Медицина» — удобная читалка научных статей одноимённого раздела научной электронной библиотеки КиберЛенинка (рубрикатор ОЭСР).

Раздел «Медицинские науки» включает:
• фундаментальную медицину;
• клиническую медицину;
• науки о здоровье;
• биотехнологии в медицине.

Возможности:
• поиск статей по всей библиотеке;
• просмотр рубрик раздела с подгрузкой списков;
• чтение полного текста статьи с настройками комфортной вёрстки;
• закладки и история чтения;
• офлайн-база: скачанные статьи доступны без интернета;
• сохранение статьи в PDF и открытие её в стороннем приложении;
• копирование ссылки и отправка статьи через мессенджеры.

Приложение бесплатное и работает по модели открытого доступа. Источник материалов — сайт cyberleninka.ru.

Внимание: приложение показывает рекламу (Appodeal), которая помогает поддерживать бесплатность проекта.

Удачного чтения!
