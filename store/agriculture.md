## Полное описание
«КиберЛенинка: Сельское хозяйство» — читалка научных статей раздела «Сельскохозяйственные науки» научной библиотеки КиберЛенинка (рубрикатор ОЭСР).

Раздел включает:
• сельское хозяйство, лесное хозяйство, рыбное хозяйство;
• животноводство и молочное дело;
• ветеринарные науки;
• агробиотехнологии.

Возможности:
• поиск статей по всей библиотеке;
• рубрики раздела с постраничной загрузкой;
• чтение полного текста с комфортной вёрсткой;
• закладки и история;
• офлайн-база для чтения без интернета;
• сохранение PDF и отправка ссылки.

Бесплатно, по модели открытого доступа. Источник — cyberleninka.ru. Приложение показывает рекламу (Appodeal).
