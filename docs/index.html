Политика конфиденциальности

Действует для мобильных приложений-читалок научных статей «КиберЛенинка» (разделы: Медицина, Естественные науки, Техника и технологии, Гуманитарные науки, Сельское хозяйство, Социальные науки). Дата последнего обновления: __ДАТА__.

1. Общие положения

Настоящая Политика описывает, какие данные обрабатываются при использовании приложений, как они используются и защищаются. Используя приложение, вы соглашаетесь с настоящей Политикой.

Разработчик: __РАЗРАБОТЧИК__. Контакт для связи: __EMAIL__.

2. Какие данные обрабатывает само приложение

Приложение не требует регистрации и не запрашивает персональные данные (имя, телефон, e-mail).

  • История чтения и закладки хранятся только локально на вашем устройстве и не передаются разработчику.
  • Сохранённые статьи и PDF хранятся в памяти устройства.

Удалить эти данные можно в приложении (пункт «Очистить офлайн-базу»), а также удалением приложения.

3. Сетевые запросы

Для поиска и загрузки статей приложение обращается к сайту cyberleninka.ru. При этом, как и при обычном посещении сайта, передаются технические данные (IP-адрес, тип устройства и приложения, запрашиваемый адрес). Обработка таких данных регулируется политикой сайта cyberleninka.ru.

4. Реклама

Приложение показывает рекламу с помощью платформы Appodeal и рекламных сетей-партнёров. Рекламные партнёры могут автоматически собирать:

  • рекламный идентификатор устройства (Advertising ID / GAID);
  • сведения об устройстве и операционной системе, язык, регион (приблизительный, по IP);
  • данные о показах и взаимодействии с рекламой.

Эти данные используются для показа и персонализации рекламы, аналитики и предотвращения мошенничества.

Подробнее:

  • Политика конфиденциальности Appodeal: https://appodeal.com/privacy-policy
  • Политики рекламных сетей-партнёров указаны в их собственных документах (Google AdMob, Yandex, VK, AppLovin, IronSource, Mintegral, Unity Ads, Vungle, Chartboost, InMobi, BidMachine, Amazon и др.).

Вы можете сбросить или ограничить использование рекламного идентификатора в настройках Android: «Настройки → Конфиденциальность → Реклама».

5. Разрешения

  • INTERNET, ACCESS_NETWORK_STATE — загрузка статей и рекламы, проверка сети.
  • WAKE_LOCK — корректная работа длительных загрузок.
  • com.google.android.gms.permission.AD_ID — использование рекламного идентификатора для рекламы.

Приложение не запрашивает доступ к геолокации, контактам, камере, микрофону, файлам и SMS.

5а. Сторонние SDK

Приложение включает рекламный SDK Appodeal и адаптеры рекламных сетей. Список сетей может меняться без обновления настоящей Политики.

6. Передача данных третьим лицам

Разработчик не продаёт и не передаёт ваши персональные данные. Технические данные передаются рекламным партнёрам (п. 4) и сайту cyberleninka.ru (п. 3) в объёме, необходимом для их работы.

7. Дети

Приложения не предназначены для детей младше 12 лет и не собирают данные о детях осознанно. Возрастной рейтинг указан в магазине приложений.

Передача данных по возможности осуществляется по HTTPS. Локальные данные доступны только самому приложению в пределах стандартной защиты операционной системы.
